| Section        | Purpose                                                   |
|----------------|-----------------------------------------------------------|
| `version:`     | Specify Compose file format version                       |
| `services:`    | Define containers                                         |
| `image:`       | Pull or use an image                                      |
| `build:`       | Build an image from a Dockerfile                          |
| `ports:`       | Map host/container ports                                  |
| `volumes:`     | Mount volumes or persist data                             |
| `environment:` | Set environment variables in the container                |
| `depends_on:`  | Control service start order                               |
| `networks:`    | Connect containers to user-defined networks               |
